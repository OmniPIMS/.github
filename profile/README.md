# OmniPIMS  
**Omni-Parameterized Information Management System**  
*A universal framework to model any product, catalog, or entity.*

OmniPIMS (OPIMS) is an open-source, schema-driven framework designed to define, store, and manage highly dynamic product structures.  
It allows organizations to model **any type of entity**—products, catalogs, policies, properties, services, configurations, and more—without changing the underlying infrastructure.

## 🔥 Core Idea
OmniPIMS provides a unified way to:
- Define entity schemas
- Manage attributes and parameters
- Store structured data dynamically
- Build product-driven experiences on top of a flexible platform

Think of it as a "PIM on steroids" designed not only for product information but *any* structured domain.

## 🎯 Key Use Cases
- Product Information Management (PIM)
- Property Information Management (real estate)
- Policy Information Management (insurance)
- Catalog & configuration services
- Risk matrices and structured entities
- Universal data modeling for apps

## 🧱 Project Structure
This organization contains the following repositories:

### **Backend (Node + Express)**
`opims-backend`  
API responsible for schema definitions, dynamic attributes, entities, versioning, and core logic.

### **Frontend (Vite + Bootstrap 5)**
`opims-frontend`  
A lightweight UI to manage schemas, attributes, entities, and configurations.
